# Demo script (about 3 minutes)

1. Landing (dark) → **Start** → coach: “I’m a backend engineer and I want to ask for a raise.”
   Answer: manager; “ninety-five” → confirm the clarification; “a hundred and ten” → confirm;
   “I don’t know the market”; fear: “budget is frozen”; opening sentence with an apology.
2. Review: show the candidate numbers, tick the labelled practice bounds, point at the three
   evidence-linked suggestions, **Confirm and start my practice**.
3. Pick Tom Becker (hardliner) → skip calibration → play: state $110,000 with a reason, justify,
   then concede to show the cost.
4. Debrief: left on the table with the formula, the ledger row for the concession and its better
   line. **Replay this round** and accept a better offer; show the comparison.
5. Fallback if anything fails: the labelled example debrief at `/example`.
