# Avatar Call Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** When `AVATAR_CALL` is `dev` or `on`, the intake's primary Start opens a LiveAvatar LITE video call with Alex (ElevenLabs agent), reusing main's intake record, tools, transcript, stop and review, with fallback to the audio call and then text.

**Architecture:** Server: env flag → `avatarIntake` capability → `PlatformDeps.liveAvatar` (REST client) → `connectVideo` in the intake service mints a session token; `stopMedia` also stops the provider session. Browser: `AvatarCall` (framework-free lifecycle controller) drives an `AvatarSession` (thin wrapper over `@heygen/liveavatar-web-sdk`), relaying captions to `/transcript` and client tool calls to `/tool` through one serial queue; `AvatarCoach.tsx` renders it. Scripts register the ElevenLabs key in LiveAvatar and sync the agent's prompt/tools from code.

**Tech Stack:** Next.js 16 route handlers, TypeScript 5.9, Zod 4, Vitest 4 (projects `intake`, `ui`), `@heygen/liveavatar-web-sdk@0.0.19` (exact; 0.0.20 is under two weeks old), ElevenLabs Agents REST API, LiveAvatar REST API.

**Spec:** `docs/superpowers/specs/2026-11-15-avatar-call-design.md`.

## Global Constraints

- `AVATAR_CALL = off | dev | on`, default `off`. With `off`, intake behaves exactly as main today (all existing tests and e2e unchanged).
- `dev` only when `NODE_ENV !== 'production'`; sandbox unless `LIVEAVATAR_SANDBOX=false`. `on` only with `LIVEAVATAR_AVATAR_APPROVED=true`, never sandbox.
- Required when not off: `LIVEAVATAR_API_KEY`, `LIVEAVATAR_AVATAR_ID`, `LIVEAVATAR_ELEVENLABS_SECRET_ID`, `ELEVENLABS_COACH_AGENT_ID`. Missing any → off.
- Keys never reach the browser. The browser receives only the LiveAvatar `session_token`. The intake view never contains the token or `providerSessionId`.
- Token request: `POST https://api.liveavatar.com/v1/sessions/token`, header `X-API-KEY`, body `{ mode: 'LITE', avatar_id, is_sandbox, max_session_duration (1..300, = remaining intake seconds), video_settings: { quality: 'high', encoding: 'H264' }, elevenlabs_agent_config: { secret_id, agent_id } }`; response `{ code: 1000, data: { session_id, session_token } }`.
- Stop: `POST https://api.liveavatar.com/v1/sessions/stop` `{ session_id, reason: 'USER_CLOSED' }`; 200/400/404/409 count as stopped.
- Budget category `avatar`, `COST_ESTIMATES.avatarPerMinute = 300_000` micro-USD; 5-minute hold per new attempt, like audio.
- Same tools and prompt as the audio coach (`COACH_INSTRUCTIONS`, `COACH_TOOLS`), single source in `src/onboarding/coach-script.ts`. First message = `GREETING`. Agent LLM `claude-sonnet-5-5`, output `pcm_24000`.
- Connect timeout 15 s; after `request_end`, end the call 2.5 s later (let Alex finish). Captions and tool calls share one serial queue, in arrival order.
- Code style: match main (2 spaces, single quotes, semicolons, `import 'server-only'` in server modules). Exact dependency versions.
- Tests: Vitest project `intake` (`tests/intake/**`, node env, `server-only` stubbed). Run `npx vitest run --project intake <file>`.

```ts
 * The avatar call is opt-in. `dev` works only outside production (LiveAvatar sandbox unless
 * LIVEAVATAR_SANDBOX=false); `on` only once a person marks the custom avatar approved, so
 * production never shows a stock face.

function readLiveAvatar(env: NodeJS.ProcessEnv, isProduction: boolean): LiveAvatarEnv | null {
  const flag = str(env.AVATAR_CALL)?.toLowerCase();
  if (flag !== 'dev' && flag !== 'on') return null;
  if (flag === 'dev' && isProduction) return null;
  if (flag === 'on' && env.LIVEAVATAR_AVATAR_APPROVED !== 'true') return null;
  const apiKey = str(env.LIVEAVATAR_API_KEY);

  const secretId = str(env.LIVEAVATAR_ELEVENLABS_SECRET_ID);
  const agentId = str(env.ELEVENLABS_COACH_AGENT_ID);
  if (!apiKey || !avatarId || !secretId || !agentId) return null;
  return { mode: flag, apiKey, avatarId, secretId, agentId, sandbox: flag === 'dev' && env.LIVEAVATAR_SANDBOX !== 'false' };
}
```

```ts
// src/onboarding/server/liveavatar.ts
import 'server-only';
import { z } from 'zod';

const API = 'https://api.liveavatar.com/v1';
const TokenResponse = z.object({
  code: z.literal(1000),
  data: z.object({ session_id: z.string().min(1).max(120), session_token: z.string().min(1).max(16_384) }),
});

export interface LiveAvatarSettings {
  apiKey: string;
  avatarId: string;
  secretId: string;
  agentId: string;
  sandbox: boolean;
}

export interface LiveAvatarClient {
  /** LITE session bound to the ElevenLabs coach agent. The API key and agent secret never leave the server. */
  mintToken(input: { maxSeconds: number }): Promise<{ sessionId: string; sessionToken: string }>;
  /** An unknown or already-ended session (the browser SDK often stops first) counts as stopped. */
  stopSession(sessionId: string): Promise<void>;
}

export class LiveAvatarError extends Error {}

export function createLiveAvatar(settings: LiveAvatarSettings, fetchImpl: typeof fetch = fetch): LiveAvatarClient {
  const headers = { 'X-API-KEY': settings.apiKey, 'Content-Type': 'application/json' };
  return {
    async mintToken({ maxSeconds }) {
      const seconds = Math.max(1, Math.min(300, Math.floor(maxSeconds)));
      const response = await fetchImpl(`${API}/sessions/token`, {
        method: 'POST',
        headers,
        cache: 'no-store',
        signal: AbortSignal.timeout(15_000),
        body: JSON.stringify({
          mode: 'LITE',
          avatar_id: settings.avatarId,
          is_sandbox: settings.sandbox,
          max_session_duration: seconds,
          video_settings: { quality: 'high', encoding: 'H264' },
          elevenlabs_agent_config: { secret_id: settings.secretId, agent_id: settings.agentId },
        }),
      });
      if (!response.ok) throw new LiveAvatarError(`LiveAvatar token request failed with ${response.status}`);
      const parsed = TokenResponse.safeParse(await response.json().catch(() => null));
      if (!parsed.success) throw new LiveAvatarError('LiveAvatar token response was not understood');
      return { sessionId: parsed.data.data.session_id, sessionToken: parsed.data.data.session_token };
    },
    async stopSession(sessionId) {
      const response = await fetchImpl(`${API}/sessions/stop`, {
        method: 'POST',
        headers,
        cache: 'no-store',
        signal: AbortSignal.timeout(8_000),
        body: JSON.stringify({ session_id: sessionId, reason: 'USER_CLOSED' }),
      });
      if (response.ok || response.status === 400 || response.status === 404 || response.status === 409) return;
      throw new LiveAvatarError(`LiveAvatar stop failed with ${response.status}`);
    },
  };
}
```

```ts
  current: IntakeSession;
  resuming: boolean;
  reservation: IntakeSession['budgetReservation'];
  now: Date;
}

/**
 * Shared start of a paid call attempt: ownership, revision and deadline checks, then one quota
 * unit and a five-minute budget hold, unless an attempt within the deadline is being resumed.
 */
async function beginMediaAttempt(deps: PlatformDeps, ownerId: string, ipHash: string, id: string, expectedRevision: number, category: 'realtime' | 'avatar', perMinute: number): Promise<MediaAttempt> {
  const current = await intakeStore(deps).readOwned(id, ownerId);
  if (current.phase === 'completed') throw new ApiError('INVALID_INPUT', 'This coach session is finished.');
  if (current.revision !== expectedRevision) throw new ApiError('VERSION_CONFLICT', 'Reload and try again.', { currentVersion: current.revision });
  const now = deps.now();
  const resuming = current.deadlineAt !== null && new Date(current.deadlineAt).getTime() > now.getTime() && current.budgetReservation !== null;
  if (current.deadlineAt && !resuming && new Date(current.deadlineAt).getTime() <= now.getTime() && current.mediaStatus !== 'closed') {
    await stopMedia(deps, ownerId, id, 'timeout');
  }
  let reservation = current.budgetReservation;
  if (!resuming) {
    await deps.quota.consume('intake', ipHash, ownerId);
    reservation = await deps.budget.reserve(category, 5 * perMinute);
  }
  return { current, resuming, reservation, now };
}

async function abandonMediaAttempt(deps: PlatformDeps, ipHash: string, attempt: MediaAttempt) {
  if (attempt.resuming) return;
  if (attempt.reservation) await deps.budget.reconcile(attempt.reservation, 0);
  await deps.quota.refund('intake', ipHash);
}

function openAttempt(s: IntakeSession, mode: 'audio' | 'video', attempt: MediaAttempt, providerSessionId: string | null): IntakeSession {
  return {
    ...s,
    mode,
    mediaStatus: 'connecting',
    phase: s.phase === 'lobby' || s.phase === 'interrupted' ? 'interviewing' : s.phase,
    providerEpoch: s.providerEpoch + 1,
    deadlineAt: attempt.resuming ? s.deadlineAt : new Date(attempt.now.getTime() + MEDIA_LIMIT_MS).toISOString(),
    budgetReservation: attempt.reservation,
    providerSessionId,
  };
}

 * Starts (or resumes) the audio call: one paid attempt per explicit connect, at most three
 * per IP per day, five minutes from the first connect. Returns a short-lived client secret.
 */
export async function connectAudio(deps: PlatformDeps, ownerId: string, ipHash: string, id: string, expectedRevision: number) {
  const env = serverEnv();
  if (!deps.capabilities.coachVoice || !env.openaiRealtime) throw new ApiError('FEATURE_DISABLED', 'The voice call is not available right now. Continue by typing.');
  const attempt = await beginMediaAttempt(deps, ownerId, ipHash, id, expectedRevision, 'realtime', COST_ESTIMATES.realtimePerMinute);
  let secret;
  try {
    secret = await mintRealtimeSecret({ apiKey: env.openaiRealtime.apiKey, model: env.openaiRealtime.model, voice: env.openaiRealtime.voice, transcribeModel: process.env.OPENAI_TRANSCRIBE_MODEL?.trim() || 'gpt-4o-mini-transcribe' });
  } catch {
    await abandonMediaAttempt(deps, ipHash, attempt);
    throw new ApiError('UPSTREAM_UNAVAILABLE', 'The voice call could not start. Continue by typing; your answers are kept.', {}, 10);
  }
  const { session } = await intakeStore(deps).update(id, (s) => openAttempt(s, 'audio', attempt, null));
  return { intake: view(deps, session), clientSecret: secret.value, expiresAt: secret.expiresAt, model: env.openaiRealtime.model, providerEpoch: session.providerEpoch, deadlineAt: session.deadlineAt! };
```

```ts
// src/onboarding/client/avatar-session.ts
import type { AvatarSessionFactory } from './avatar-call';

/** ElevenLabs client_tool_call payloads arrive either wrapped in `client_tool_call` or flat. */
export function toolCall(type: string, data: Record<string, unknown>): { id: string; name: string; args: string } | null {
  if (type !== 'client_tool_call') return null;
  const raw = (data.client_tool_call ?? data) as Record<string, unknown>;
  if (typeof raw.tool_call_id !== 'string' || typeof raw.tool_name !== 'string') return null;
  return { id: raw.tool_call_id, name: raw.tool_name, args: JSON.stringify(raw.parameters ?? {}) };
}

/**
 * Thin wrapper over the LiveAvatar SDK's ElevenLabs agent session, loaded only when a video call
 * starts. The microphone starts muted; the caller unmutes once the attempt is confirmed current.
 */
export const createAvatarSession: AvatarSessionFactory = async (token, callbacks) => {
  const { ElevenLabsAgentSession, AgentEventsEnum, SessionEvent, VoiceChatState } = await import('@heygen/liveavatar-web-sdk');
  const session = new ElevenLabsAgentSession(token, { autoKeepAlive: true, voiceChat: { defaultMuted: true } });
  let media: HTMLVideoElement | null = null;
  session.on(AgentEventsEnum.USER_TRANSCRIPTION, (e) => callbacks.caption('user', e.text, e.event_id));
  session.on(AgentEventsEnum.AVATAR_TRANSCRIPTION, (e) => callbacks.caption('coach', e.text, e.event_id));
  session.on(AgentEventsEnum.AVATAR_SPEAK_STARTED, () => callbacks.speaking(true));
  session.on(AgentEventsEnum.AVATAR_SPEAK_ENDED, () => callbacks.speaking(false));
  session.on(AgentEventsEnum.ELEVENLABS_AGENT_EVENT, (e) => {
    const call = toolCall(e.elevenlabs_event_type, e.data);
    if (call) callbacks.tool(call.id, call.name, call.args);
  });
  session.on(SessionEvent.SESSION_DISCONNECTED, () => callbacks.disconnected());
  return {
    async start() {
      await session.start();
      // The SDK can resolve start() after swallowing a microphone error; trust its public state.
      if (session.voiceChat.state !== VoiceChatState.ACTIVE) {
        session.voiceChat.stop();
        await session.stop().catch(() => undefined);
        throw new Error('The microphone did not start.');
      }
    },
    attach(element) {
      media = element;
      session.attach(element);
    },
    setMuted: (muted) => (muted ? session.voiceChat.mute() : session.voiceChat.unmute()),
    sendToolResult(callId, result) {
      session.sendClientToolResult({ toolCallId: callId, result });
    },
    async stop() {
      session.voiceChat.stop();
      if (media) {
        media.pause();
        media.srcObject = null;
      }
      await session.stop().catch(() => undefined);
    },
  };
};
```

```ts
export type AvatarStopReason = 'end' | 'timeout' | 'error' | 'fallback';
export type AvatarCallState = 'idle' | 'connecting' | 'active' | 'ending' | 'ended';

export interface AvatarCallApi {
  connect(): Promise<{ intake: IntakeView; sessionToken: string; providerEpoch: number }>;
  transcript(providerEpoch: number, itemId: string, role: 'user' | 'coach', text: string): Promise<IntakeView>;
  tool(providerEpoch: number, callId: string, name: string, args: string): Promise<{ output: Record<string, unknown> }>;
  stop(reason: AvatarStopReason): Promise<IntakeView>;
}

export interface AvatarCallEvents {
  state(state: AvatarCallState): void;
  view(view: IntakeView): void;
  speaking(on: boolean): void;
  /** The call could not start or dropped; the screen continues with the next coach. */
  failed(message: string): void;
}

export const CONNECT_TIMEOUT_MS = 15_000;
export const GOODBYE_MS = 2_500;

/**
 * One video call attempt per instance. After `end`, every late SDK event is ignored, so nothing
 * from a closed call reaches the server or the screen. Captions and tool calls share one queue in
 * arrival order: the server accepts a tool's quote only once the user's words are on record.
 */
export class AvatarCall {
  state: AvatarCallState = 'idle';
  private closed = false;
  private session: AvatarSession | null = null;
  private video: HTMLVideoElement | null = null;
  private epoch = 0;
  private queue: Promise<void> = Promise.resolve();
  private ending: Promise<void> | null = null;

  constructor(
    private readonly api: AvatarCallApi,
    private readonly factory: AvatarSessionFactory,
    private readonly events: AvatarCallEvents,
  ) {}

  async start(): Promise<void> {
    if (this.state !== 'idle') return;
    this.setState('connecting');
    const timeout = setTimeout(() => {
      if (this.state === 'connecting') void this.fail('Connecting to Alex took too long. Your answers are kept.');
    }, CONNECT_TIMEOUT_MS);
    try {
      const credentials = await this.api.connect();
      if (this.closed) {
        // Abandoned while the server was minting: close the session it just opened.
        await this.api.stop('fallback').catch(() => undefined);
        return;
      }
      this.epoch = credentials.providerEpoch;
      this.events.view(credentials.intake);
      const session = await this.factory(credentials.sessionToken, this.callbacks());
      if (this.closed) {
        await session.stop();
        return;
      }
      this.session = session;
      if (this.video) session.attach(this.video);
      await session.start();
      if (this.closed) return;
      await session.setMuted(false);
      if (this.closed) return;
      this.setState('active');
    } catch (err) {
      if (!this.closed) await this.fail(err instanceof ApiClientError ? err.message : 'Alex could not connect. Check your microphone; your answers are kept.');
    } finally {
      clearTimeout(timeout);
    }
  }

  attach(element: HTMLVideoElement): void {
    this.video = element;
    this.session?.attach(element);
  }

  async mute(muted: boolean): Promise<void> {
    await this.session?.setMuted(muted);
  }

  /** Releases the microphone locally first, then closes the intake's media on the server. */
  end(reason: AvatarStopReason): Promise<void> {
    if (this.ending) return this.ending;
    this.closed = true;
    this.setState('ending');
    const session = this.session;
    this.session = null;
    this.ending = (async () => {
      await session?.stop().catch(() => undefined);
      try {
        this.events.view(await this.api.stop(reason));
      } catch {
        // The screen re-reads the intake on fallback or review.
      }
      this.setState('ended');
    })();
    return this.ending;
  }

  private async fail(message: string): Promise<void> {
    await this.end('fallback');
    this.events.failed(message);
  }

  private setState(state: AvatarCallState) {
    this.state = state;
    this.events.state(state);
  }

  private enqueue(task: () => Promise<void>) {
    this.queue = this.queue
      .then(async () => {
        if (!this.closed) await task();
      })
      .catch(() => undefined);
  }

  private callbacks(): AvatarSessionCallbacks {
    return {
      caption: (role, text, itemId) => {
        const clean = text.trim().slice(0, 4_000);
        if (!clean || this.closed) return;
        this.enqueue(async () => this.events.view(await this.api.transcript(this.epoch, itemId, role, clean)));
      },
      tool: (callId, name, args) => {
        if (this.closed) return;
        this.enqueue(async () => {
          let output: Record<string, unknown>;
          try {
            output = (await this.api.tool(this.epoch, callId, name, args)).output;
          } catch {
            output = { ok: false, error: 'The server did not accept this call.' };
          }
          if (this.closed) return;
          this.session?.sendToolResult(callId, JSON.stringify(output));
          if (name === 'request_end') setTimeout(() => void this.end('end'), GOODBYE_MS);
        });
      },
      speaking: (on) => {
        if (!this.closed) this.events.speaking(on);
      },
      disconnected: () => {
        if (!this.closed) void this.fail('The call dropped. Your answers are kept.');
      },
    };
  }
}
```

```ts
// src/onboarding/ui/coach-choice.ts
import type { IntakeView } from '../contracts';

export type CoachKind = 'video' | 'audio' | 'text';

/** The coach the intake screen shows: the chosen mode when available, then each fallback in turn. */
export function coachFor(view: IntakeView, fallback: CoachKind | null): CoachKind {
  if (fallback === null && view.mode === 'video' && view.availability.avatarIntake) return 'video';
  const voiceMode = view.mode === 'audio' || view.mode === 'video';
  if (fallback !== 'text' && voiceMode && view.availability.coachVoice) return 'audio';
  return 'text';
}

export function nextFallback(view: IntakeView, from: CoachKind): CoachKind {
  return from === 'video' && view.availability.coachVoice ? 'audio' : 'text';
}
```

```ts
// scripts/avatar/elevenlabs-agent.ts
import { COACH_INSTRUCTIONS, COACH_TOOLS } from '@/onboarding/coach-script';
import { GREETING } from '@/onboarding/domain/interviewer';

export const COACH_LLM = 'claude-sonnet-5-5';
export const OUTPUT_FORMAT = 'pcm_24000';

export interface ClientToolConfig {
  type: 'client';
  name: string;
  description: string;
  expects_response: true;
  response_timeout_secs: number;
  parameters?: { type: 'object'; properties: Record<string, unknown>; required: string[] };
}

export interface AgentSnapshot {
  conversation_config?: {
    agent?: { first_message?: string; prompt?: { prompt?: string; llm?: string; tool_ids?: string[] } };
    tts?: { agent_output_audio_format?: string };
  };
}

/** ElevenLabs client tools from the coach's OpenAI-style function tools (no additionalProperties; no empty schemas). */
export function clientToolConfigs(): ClientToolConfig[] {
  return COACH_TOOLS.map((tool) => {
    const params = tool.parameters as { properties: Record<string, unknown>; required?: readonly string[] };
    const hasParams = Object.keys(params.properties).length > 0;
    return {
      type: 'client',
      name: tool.name,
      description: tool.description,
      expects_response: true,
      response_timeout_secs: 20,
      ...(hasParams ? { parameters: { type: 'object' as const, properties: params.properties, required: [...(params.required ?? [])] } } : {}),
    };
  });
}

export function agentPatch(toolIds: string[]) {
  return {
    conversation_config: {
      agent: { first_message: GREETING, prompt: { prompt: COACH_INSTRUCTIONS, llm: COACH_LLM, tool_ids: toolIds } },
      tts: { agent_output_audio_format: OUTPUT_FORMAT },
    },
  };
}

const short = (s: string | undefined) => (s === undefined ? '(none)' : s.length > 60 ? `${s.slice(0, 57)}…` : s);

/** Human-readable differences between the live agent and what the code expects. */
export function describeDrift(agent: AgentSnapshot, attachedToolNames: string[]): string[] {
  const a = agent.conversation_config?.agent;
  const lines: string[] = [];
  if (a?.prompt?.prompt !== COACH_INSTRUCTIONS) lines.push('prompt: will be replaced with the audio coach instructions');
  if (a?.prompt?.llm !== COACH_LLM) lines.push(`llm: ${a?.prompt?.llm ?? '(none)'} → ${COACH_LLM}`);
  if (a?.first_message !== GREETING) lines.push(`first message: "${short(a?.first_message)}" → "${short(GREETING)}"`);
  const format = agent.conversation_config?.tts?.agent_output_audio_format;
  if (format !== OUTPUT_FORMAT) lines.push(`output format: ${format ?? '(default)'} → ${OUTPUT_FORMAT}`);
  const missing = COACH_TOOLS.map((t) => t.name).filter((n) => !attachedToolNames.includes(n));
  if (missing.length) lines.push(`client tools to attach: ${missing.join(', ')}`);
  return lines;
}
```

```ts
// scripts/avatar-sync-agent.ts
/**
 * Keeps the ElevenLabs "Holdline Coach" agent identical to the audio coach: prompt, first
 * message, client tools, LLM and PCM 24K output. Dry run by default; writes only with --apply.
 */
import { agentPatch, clientToolConfigs, describeDrift, type AgentSnapshot } from './avatar/elevenlabs-agent';

const API = 'https://api.elevenlabs.io/v1/convai';
const key = process.env.ELEVENLABS_API_KEY?.trim();
const agentId = process.env.ELEVENLABS_COACH_AGENT_ID?.trim();
const apply = process.argv.includes('--apply');

async function call<T>(path: string, init: RequestInit = {}): Promise<T> {
  const response = await fetch(`${API}${path}`, { ...init, headers: { 'xi-api-key': key!, 'Content-Type': 'application/json' }, signal: AbortSignal.timeout(20_000) });
  const body = (await response.json().catch(() => null)) as T;
  if (!response.ok) throw new Error(`${init.method ?? 'GET'} ${path} failed with ${response.status}: ${JSON.stringify(body).slice(0, 500)}`);
  return body;
}

interface ToolRecord { id: string; tool_config?: { name?: string } }

async function main() {
  if (!key) throw new Error('Add ELEVENLABS_API_KEY to .env.local first.');
  if (!agentId) {
    const { agents } = await call<{ agents: { agent_id: string; name: string }[] }>('/agents?search=Holdline');
    console.log('ELEVENLABS_COACH_AGENT_ID is not set. Agents matching "Holdline":');
    for (const a of agents) console.log(`  ${a.agent_id}  ${a.name}`);
    process.exitCode = 1;
    return;
  }
  const agent = await call<AgentSnapshot>(`/agents/${encodeURIComponent(agentId)}`);
  const { tools } = await call<{ tools: ToolRecord[] }>('/tools');
  const attached = new Set(agent.conversation_config?.agent?.prompt?.tool_ids ?? []);
  const attachedNames = tools.filter((t) => attached.has(t.id)).map((t) => t.tool_config?.name ?? '');
  const drift = describeDrift(agent, attachedNames);
  if (!drift.length) {
    console.log('The agent already matches the coach.');
    return;
  }
  console.log('Changes for the agent:');
  for (const line of drift) console.log(`  - ${line}`);
  if (!apply) {
    console.log('\nDry run. Re-run with --apply to write these settings.');
    return;
  }
  const ids: string[] = [];
  for (const config of clientToolConfigs()) {
    const existing = tools.find((t) => t.tool_config?.name === config.name);
    if (existing) {
      await call(`/tools/${encodeURIComponent(existing.id)}`, { method: 'PATCH', body: JSON.stringify({ tool_config: config }) });
      ids.push(existing.id);
    } else {
      const created = await call<{ id: string }>('/tools', { method: 'POST', body: JSON.stringify({ tool_config: config }) });
      ids.push(created.id);
    }
  }
  await call(`/agents/${encodeURIComponent(agentId)}`, { method: 'PATCH', body: JSON.stringify(agentPatch(ids)) });
  console.log('Agent updated.');
}

main().catch((err: unknown) => {
  console.error(err instanceof Error ? err.message : err);
  process.exitCode = 1;
});
```

```ts
// scripts/avatar-register-secret.ts
/** One-time: stores the ElevenLabs key in LiveAvatar's secret store and prints its reference id. Never prints the key. */
import { z } from 'zod';

async function main() {
  const env = z.object({ LIVEAVATAR_API_KEY: z.string().min(1), ELEVENLABS_API_KEY: z.string().min(1) }).safeParse(process.env);
  if (!env.success) throw new Error('Add LIVEAVATAR_API_KEY and ELEVENLABS_API_KEY to .env.local first.');
  const response = await fetch('https://api.liveavatar.com/v1/secrets', {
    method: 'POST',
    headers: { 'X-API-KEY': env.data.LIVEAVATAR_API_KEY, 'Content-Type': 'application/json' },
    signal: AbortSignal.timeout(15_000),
    body: JSON.stringify({ secret_type: 'ELEVENLABS_API_KEY', secret_name: 'Holdline Coach', secret_value: env.data.ELEVENLABS_API_KEY }),
  });
  if (!response.ok) throw new Error(`LiveAvatar rejected the secret (${response.status}). Check the account, key permissions and plan. No secret value is logged.`);
  const result = z.object({ code: z.literal(1000), data: z.object({ id: z.string().min(1) }) }).parse(await response.json());
  console.log('Secret registered. Add this reference id (not a key) to .env.local:');
  console.log(`LIVEAVATAR_ELEVENLABS_SECRET_ID=${result.data.id}`);
}

main().catch((err: unknown) => {
  console.error(err instanceof Error ? err.message : err);
  process.exitCode = 1;
});
```
