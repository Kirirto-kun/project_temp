# Holdline. План 3 из 4. Интерфейс, клиентский голос и пользовательский опыт

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** собрать общий путь от первого знакомства D до денежного/голосового разбора, запасную форму и reusable захват аудио; продукт работает без регистрации и сохраняет данные при переходе между режимами.

**Architecture:** страницы Next.js и изолированные feature-модули используют общий API-клиент и контракты A. UI не решает исход переговоров. Браузер записывает только микрофон пользователя, извлекает акустику и передаёт manifest серверу B для объединения со Scribe.

**Tech Stack:** React/Next.js, TypeScript, Tailwind, shadcn/ui, Lucide, `@elevenlabs/react`, Web Audio, MediaRecorder, pitchfinder, Vitest/Testing Library и Playwright. Версии и зависимости вносит B в общий lockfile.

**Spec:** [PLAN.md](../../../PLAN.md), особенно §3, §5–10, §12–15; [brandbook.html](../../../brandbook.html); [контракты A](2026-11-15-01-engine.md), [API и порядок слияния B](2026-11-15-02-platform.md), [первый созвон D](2026-11-15-04-avatar-intake.md).

**Разработчик:** C. **Ветка:** `codex/holdline-product`.

## Общие ограничения

- Все экраны 0→7 и пример разбора доступны без регистрации и покупки.
- «Источник истины: brandbook.html». Английские UI-тексты; русский язык этих планов не задаёт локализацию продукта.
- Каталог переговорных персонажей — 6–8 плоских иллюстраций и четыре архетипа. Брендбук разрешает отдельный лицензированный цифровой host для вводного звонка D с видимой меткой AI coach.
- Числа из API отображаются, а не пересчитываются собственной копией переговорного движка.
- «Текстовый режим доступен на каждом шаге»; отказ микрофона и недоступность Agent не блокируют тренировку.
- Показатели делятся на измерения, индекс с формулой и оценку модели. Недоступные данные не заменяются нулём.

## На что обратить внимание при ревью

1. Отказ микрофона, неподдерживаемый recorder, разрыв Agent и переключение режима сохраняют состояние — C3/C4.
2. Двойная отправка, 409, reload и два открытых окна не рисуют несуществующий ход — C2/C4.
3. Без baseline и без согласия на запись нет сравнений «к норме» и выдуманной напряжённости — C3/C5.
4. В аренде, отсутствии сделки и переигровке суммы и периоды отображаются честно — C2/C5/C6.
5. Клавиатура, небольшой экран, dark mode и медленная загрузка не делают путь непроходимым — C1/C7/C8.

Возврат в форму сохраняет введённые ответы; прямой URL без контекста возвращает на подходящий шаг. Создание тренировки происходит после review/подтверждения, заполнения missingFields, выбора персонажа и baseline/skip. Для intake C передаёт B только intakeId/profileRevision/avatarId/baselineId; сервер загружает handoff. Review D закрывает платную медиасессию; начало ElevenLabs запрещено, пока старый room и capture не закрыты. Reload восстанавливает owner-bound данные с сервера; salary/transcript не кладутся в URL/аналитику/localStorage по умолчанию.

## 3. Визуальная система

Перенести значения из брендбука, включая полную dark theme. Основные пары light/dark: `paper #F4F6F8/#0C1218`, `raised #FFFFFF/#151D26`, `ink #101820/#EEF1F5`, `hold #1B4DFF/#6C8BFF`, `won #0E7A3E/#3DD68C`, `gap #B45309/#FFB454`. Остальные line/muted/tint/on-hold — также из источника.

- Bricolage Grotesque 700 — заголовки; Instrument Sans 400/500/600 — текст; IBM Plex Mono 500 с tabular-nums — деньги и числовые показатели. Предусмотреть font fallback без скачка, мешающего нажать кнопку.
- Сетка 4px, отступ на телефоне 16px, радиусы 4/8/12, рамки 1px, одна тонкая тень. Без градиентов, стекла и glow.
- Разговор — колонка до 720px; разбор — две колонки выше 900px. На узком экране деньги и голос одного хода стоят рядом по смыслу, не расходятся в две несвязанные ленты.
- Кнопки высотой минимум 44px; одна primary на экран. Фокус: 2px hold, отступ 2px. Контраст текста ≥4.5:1 в обеих темах.
- Шкалы 0…100; ниже 25 — amber и подпись `low`. Цвет всегда сопровождается словом, знаком или числом.
- Lucide 20px, stroke 1.5; смысловые иконки имеют доступные подписи. Нет emoji как иконок.
- Анимация ограничена typing/speaking indicator и изменением шкал 200ms ease-out; `prefers-reduced-motion` отключает лишнее движение. Нет вступительной анимации страницы.
- Тон: цифра первой, спокойное объяснение действия, без восклицаний, давления, «unlock» и обещаний реальных заработков. В расчётах — `against your range`.
