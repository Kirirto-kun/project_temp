## 1. Цель одним абзацем

Веб-симулятор разговора о деньгах. Пользователь говорит, к чему готовится, выбирает собеседника из каталога, записывает 30 секунд своего голоса для калибровки, затем **голосом** ведёт переговоры с собеседником, который не уступает просто так. После разговора видит разбор в два слоя: **деньги** (сколько оставил на столе и на каком ходу) и **голос** (темп, паузы, паразиты, напряжение относительно своей нормы). Может переиграть ту же партию.

Ставка на оценку: 40% «работает» закрываем детерминированным ядром и стабильным продом; новизну и «зачем вернутся» закрываем голосовым слоем, которого у ChatGPT-ролеплея нет.

## 3. Продукт

### 3.1 Пользователь и боль
**Пользователь №1:** IT-специалист, у которого в ближайшие недели разговор об оффере или повышении. Рынок англоязычный, интервью берём у своих.
**Боль:** самые дорогие разговоры жизни проходят без единой репетиции. Человек либо не просит, либо сдаётся на первом «бюджет заморожен».
**Рамка бренда (шире):** любой разговор, где ты просишь деньги или скидку: оффер, повышение, аренда, счёт, ставка по карте, ставка фрилансера. Вход и демо узкие, бренд широкий.

### 3.2 Путь пользователя (экраны)

| # | Экран | Что происходит | Данные |
|---|---|---|---|
| 0 | Вход | «К какому разговору готовишься?» Поле + чипы (повышение, оффер, аренда, клиент, счёт) | `conversationType`, свободный текст |
| 1 | Квиз, 4–5 экранов | Кто собеседник, дата, цифры (текущая, желаемая, рыночный диапазон), чего боишься, архетип собеседника | `QuizAnswers` |
| 2 | Результат квиза | «Ты теряешь около $X в год» с формулой. Полоса оффера | расчёт кодом |
| 3 | Собеседник | Каталог 6–8 аватаров, карточка (имя, роль, стаж), архетип поведения | `avatarId`, `archetype` |
| 4 | Калибровка голоса | Запрос микрофона, чтение 20-секундного текста. Кнопка «пропустить» | `VoiceBaseline` |
| 5 | Сессия | Голосовой разговор через ElevenLabs Agent. На экране: аватар, транскрипт, шкалы терпения и доверия, одна живая голосовая метрика (темп к базе) | `SessionState`, аудио пользователя |
| 6 | Разбор | Полоса оффера, журнал ходов (деньги + голос на одной шкале времени), «оставил на столе», лучшая фраза на каждый плохой ход | `Debrief` |
| 7 | Переигровка | Та же партия, тот же конфиг, метрики рядом | новая `SessionState` |
| 8 | План | Очередь разговоров с датами, счётчик выигранного | localStorage |
| 9 | Оплата | Пакет на разговор $9–19 через Polar. Платная функция: свой сценарий по описанию и разбор реального оффера | Polar checkout |

**Для жюри весь путь 0→7 бесплатный.** Пейволл стоит только перед генератором своего сценария.

**Текстовый режим** доступен на каждом шаге: если микрофон не дали или Agent не поднялся, сессия идёт чатом через тот же эндпоинт.

## 4. Архитектура

```
Браузер (Next.js)
 ├─ Квиз, каталог, разбор, план ............ React + Tailwind + shadcn/ui
 ├─ Голосовая сессия ....................... @elevenlabs/client (Agent WebRTC/WS)
 ├─ Живые метрики .......................... Web Audio: RMS, паузы, F0 (pitchfinder)
 ├─ Запись пользователя .................... MediaRecorder → upload после сессии
 └─ localStorage ........................... квиз, базовая линия, история, план

Сервер (Next.js API routes / Route Handlers)
 ├─ POST /api/session ...................... создать сессию, собрать ScenarioConfig (Сценарист)
 ├─ POST /api/llm/v1/chat/completions ...... custom LLM для ElevenLabs Agent:
 │     реплика → Классификатор → Ядро → Актёр → SSE-стрим текста
 ├─ POST /api/turn ......................... тот же пайплайн для текстового режима
 ├─ POST /api/voice/baseline ............... Scribe batch → VoiceBaseline
 ├─ POST /api/voice/analyze ................ Scribe batch по записи сессии → VoiceMetrics по ходам
 ├─ POST /api/debrief ...................... суммы кодом, комментарии LLM
 ├─ POST /api/elevenlabs/token ............. одноразовый токен для клиента
 ├─ POST /api/polar/webhook ................ оплата
 └─ Rate limit по IP + глобальный потолок расходов

Хранилище
 ├─ Состояние сессии: Redis/Upstash или in-memory Map с TTL (сессии короткие)
 └─ Аудио: временно в объектном хранилище (S3/R2), удаление через 24 ч

Внешние сервисы
 ├─ ElevenLabs: Agents (сессия), Scribe (STT с таймстемпами), TTS (голоса аватаров), IVC (клон, опционально)
 ├─ LLM: быстрая модель для Классификатора, обычная для Актёра/Сценариста/Разборщика
 └─ Polar: оплата
```

### 4.1 Движок: четыре агента вокруг детерминированного ядра

| Агент | Тип | Вход → выход | Когда |
|---|---|---|---|
| Сценарист | LLM, 1 раз | QuizAnswers → `ScenarioConfig` по строгой JSON-схеме | старт сессии |
| Классификатор | LLM, быстрая модель | реплика пользователя → `{moveType, amount?, hasReason, tone}` | каждый ход |
| Ядро | чистый TypeScript | `(CoreState, Move)` → `(CoreState', CounterpartAction)` | каждый ход |
| Актёр | LLM, стрим | `CounterpartAction` + персонаж → текст реплики | каждый ход |
| Разборщик | код + LLM | `SessionState` + `VoiceMetrics` → `Debrief` | конец сессии |

**Правила:**
- Все цифры считает код. Актёр получает число от ядра и не имеет права его менять; после генерации текст проверяется регуляркой на совпадение сумм.
- Классификатор возвращает только значения из закрытого списка. Невалидный ответ → повтор один раз → `offtopic`.
- Ядро покрыто юнит-тестами на таблицу переходов. Классификатор покрыт 30 тестовыми репликами.

### 4.2 Модель данных (черновик)

```ts
type MoveType =
  | 'state_number' | 'justify' | 'concede' | 'ask_question'
  | 'hold_silence' | 'ultimatum' | 'accept' | 'offtopic';

interface Move { type: MoveType; amount?: number; hasReason: boolean; raw: string; t0: number; t1: number; }

interface ScenarioConfig {
  kind: 'raise' | 'offer' | 'rent' | 'bill' | 'custom';
  currency: 'USD';
  userCurrent: number; userTarget: number; marketLow: number; marketHigh: number;
  ceiling: number;            // из рыночного диапазона, не выдумка
  concessionStep: number;     // на сколько уступает за раз
  objections: Objection[];    // список с условиями снятия
  persona: { name: string; role: string; archetype: Archetype; voiceId: string; avatarId: string };
  patience0: number; trust0: number;
}

interface Objection { id: string; text: string; clearedBy: MoveType[]; cleared: boolean; }

interface CoreState {
  offer: number | null;        // текущее предложение собеседника
  userLast: number | null;     // последняя цифра пользователя
  patience: number; trust: number;   // 0..100
  objections: Objection[];
  turn: number;
  ended?: 'accepted' | 'walked_away' | 'timeout';
}

type CounterpartAction =
  | { kind: 'hold' } | { kind: 'concede'; to: number } | { kind: 'object'; objectionId: string }
  | { kind: 'accept'; at: number } | { kind: 'walk_away' } | { kind: 'probe' };

interface VoiceBaseline { wpm: number; f0Mean: number; f0Std: number; pauseRatio: number; rms: number; fillersPerMin: number; }

interface TurnVoice { turn: number; wpm: number; f0Mean: number; f0Std: number; pauseBeforeNumberMs?: number; fillers: number; rmsDipAtNumber: boolean; tension: number; }

interface DebriefRow { turn: number; move: MoveType; note: string; moneyEffect?: number; meterEffect?: { patience?: number; trust?: number }; voice?: TurnVoice; betterLine?: string; }

interface Debrief { leftOnTable: number; ceiling: number; stoppedAt: number; rows: DebriefRow[]; persuasionScore: { value: number; rationale: string }; }
```

### 4.3 Таблица переходов ядра (набросок, довести в коде)

| Ход пользователя | Условие | Эффект на состояние | Действие собеседника |
|---|---|---|---|
| `state_number` с обоснованием | amount ≤ ceiling | trust +3 | `concede` на шаг к amount, если открытых возражений нет; иначе `object` |
| `state_number` без обоснования | | patience −2 | `object` (первое открытое) |
| `state_number` | amount > ceiling·1.15 | patience −5 | `hold` + возражение «вне диапазона» |
| `justify` | закрывает условие возражения | возражение cleared, trust +2 | `concede` на шаг |
| `concede` | пользователь снизил цифру | фиксируем «оставил на столе» += разница | `accept`, если ≤ offer+step, иначе `hold` |
| `ask_question` | | patience +1 | `probe` (раскрывает подсказку) |
| `hold_silence` | после возражения | patience −1, trust +1 | `concede` на полшага |
| `ultimatum` | trust < 40 | patience −10 | `walk_away` при patience < 15, иначе `hold` |
| `ultimatum` | trust ≥ 40 | | `concede` на шаг |
| `accept` | | ended = accepted | — |
| `offtopic` | | patience −1 | `hold` |
| любой | patience ≤ 0 | ended = walked_away | `walk_away` |

«Оставил на столе» = `ceiling − финальная сумма` при принятии, плюс каждая уступка ниже уже достигнутого.

## 5. Голосовой контур на ElevenLabs

### 5.1 Сессия: Agent + наш сервер как custom LLM
- Создаём Agent в дашборде ElevenLabs, LLM = custom, URL = `https://<prod>/api/llm/v1/chat/completions`, ключ в заголовке.
- Голос агента подменяем на лету под аватар (`voiceId` из `ScenarioConfig`), через overrides при старте сессии.
- В `elevenlabs_extra_body` передаём `sessionId`, чтобы сервер поднял нужное `CoreState`.
- Сервер отвечает SSE в формате OpenAI chat.completions. Первым чанком отдаём «buffer words» («Hm... »), пока считаются классификатор и ядро.
- Клиент: `@elevenlabs/client` или `@elevenlabs/react`, старт по одноразовому токену с `/api/elevenlabs/token`. Ключ API в браузер не попадает.
- Параллельно пишем микрофон пользователя через MediaRecorder (нужно для пакетного анализа).

### 5.2 Калибровка
- 20 секунд чтения нейтрального текста → `POST /api/voice/baseline` → Scribe batch с таймстемпами слов → `VoiceBaseline`.
- Параллельно в браузере считаем RMS и F0, чтобы базовая линия была и для живых метрик.
- Кнопка «Пропустить»: метрики в разборе абсолютные, без сравнения, с пометкой.

### 5.3 Разбор голоса
- Запись сессии (только дорожка пользователя) → `POST /api/voice/analyze` → Scribe batch, verbatim, таймстемпы.
- Режем по ходам (границы известны из сессии), считаем на каждый ход: темп, паразиты, паузу перед первой цифрой, провал громкости в момент цифры, F0 среднее и разброс.
- `tension` = взвешенная сумма отклонений от базовой линии (рост F0, рост темпа, доля пауз). Формула показана на экране.
- `persuasionScore` считает LLM по рубрике (аргумент, цифра с обоснованием, нет извинений, нет уступки без причины). Подписывается как «оценка модели».

### 5.4 Опционально: «Послушать, как надо, твоим голосом»
- Из калибровочной записи делаем мгновенный клон (IVC), озвучиваем `betterLine` голосом пользователя.
- Явное согласие галочкой, удаление клона после сессии. Проверить качество до включения в питч.

### 5.5 Защита расходов
- Сессия ≤ 5 минут, автозавершение.
- ≤ 3 сессии на IP в день, глобальный дневной потолок минут.
- Проверить в дашборде, сколько минут Agents и Scribe дают имеющиеся кредиты. Оставить запас на жюри ×10 сессий.

### 5.6 Проверить в первые два часа
- Verbatim в Scribe правда оставляет «um/uh» (от этого зависит метрика паразитов).
- Agent работает в Safari и Chrome на macOS, на телефоне хотя бы не падает.
- Задержка хода с buffer words укладывается в 3–5 с.

- Фирменные элементы: полоса оффера, шкалы, журнал ходов.
- Аватары: плоские иллюстрации, без сгенерированных лиц.
- Голос: цифра первой, без восклицаний, без давления, честно про симуляцию («против твоего диапазона», не «босс бы заплатил»).

## 10. Дек, 10 слайдов

1. Название, одна строка: «Отрепетируй разговор до того, как он обойдётся тебе в деньги».
2. Боль: цитата из интервью + одна проверенная цифра.
3. Пользователь: кто, когда, что теряет (с формулой «$X в год»).
4. Продукт за 20 секунд: квиз → собеседник → разговор → разбор. Скриншоты.
5. Почему не ChatGPT: скрытое состояние, не сдаётся, честный разбор. Сравнение из двух реплик.
6. Голосовой слой: журнал с двумя колонками, «на 4-м ходу голос поднялся на 18% и ты уступил $8 000».
7. Как устроено: ядро на TS, LLM по краям, ElevenLabs. Схема из раздела 4.
8. Деньги: пакет на разговор, платный генератор, честная LTV как гипотеза.
9. Рынок и расширение: все разговоры о деньгах, один движок, сценарий = конфиг.
10. Команда, что сделали за 24 часа, что дальше.

## 11. Вопросы жюри и ответы

- **Откуда вы знаете потолок?** Это параметр сценария, взятый из диапазона, который ввёл пользователь. Мы говорим «против твоего диапазона», а не «твой босс бы заплатил».
- **Почему не дать ИИ торговаться за меня?** Счёт делегировать можно, разговор с начальником или арендодателем нет: его произносит сам человек.
- **Зачем вернутся?** Разговоры о деньгах случаются несколько раз в год, очередь разговоров с датами, переигровка, новые сценарии.
- **Чем отличается от тренажёров переговоров?** Скрытое состояние и счёт денег, а не оценка «молодец». Плюс голос относительно твоей нормы.
- **Что захардкожено?** Ничего в цифрах: все суммы считает ядро, LLM их не трогает. Репо открыт.
- **Насколько точны голосовые метрики?** Темп, паузы, паразиты, громкость, высота: измерения. Напряжение: индекс с видимой формулой. Убедительность: оценка модели, подписана как оценка.
