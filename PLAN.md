## 1. Цель и текущий объём

Веб-подготовка к любому разговору. Спокойный AI-коуч выясняет ситуацию, собеседника или аудиторию, желаемый результат, optional тон и опасения; предлагает короткую пробу вступления. Пользователь проверяет и явно подтверждает brief. Камера необязательна и остаётся локальной; форма позволяет подготовиться без звонка и provider keys.

Общий QuizAnswers/API v2: kind/description/goal/counterpartRole; optional desiredTone. QuizDraft partial, старые зарплатные данные читаются. Деньги, диапазон, дата и avatar необязательны. missingFields относится только к общей подготовке; подтверждённый brief не доказывает readiness финансового движка.

Текущая реализация не объявляет готовыми отдельные полноценные roleplay/debrief, детерминированный финансовый движок или речевой/визуальный анализ. Финансовая симуляция может позже использовать подтверждённый профиль и собственную строгую проверку сумм/единиц/диапазона. Она не ограничивает список возможных тем и не превращает custom-разговор в платный финансовый сценарий.

## 3. Продукт: универсальная подготовка

### 3.1 Пользователь и задача

Человек, которому предстоит важный разговор: собеседование, feedback, конфликт, договорённость с близким, выступление, денежный вопрос или любая собственная тема. Достаточно описать ситуацию, с кем предстоит говорить и чего хочется достичь. Профессия, зарплата и рыночный диапазон не являются общими требованиями.

### 3.2 Текущий путь

| Шаг | Экран | Поведение |
|---|---|---|
| 0 | Приглашение | “Prepare for your next conversation.” AI coach, камера optional; нет devices/paid session до действия |
| 1 | Lobby | Явная проверка микрофона, local self-view по желанию; форма при отказе |
| 2 | Контекст | kind, ситуация, собеседник/аудитория, goal, optional desiredTone/concerns/userRole; одна основная реплика-вопрос |
| 3 | Короткая проба | Необязательная вступительная фраза или отрывок презентации; это подготовка, не полноценный roleplay |
| 4 | Review | Платная медиасессия закрыта; человек видит тип/ситуацию/цель и правит данные |
| 5 | Confirm / handoff | Только человеческое подтверждение; owner-bound draft и common missingFields, без обещания финансовой готовности |

Форма и разговор используют один QuizDraft. custom принимает произвольную тему. Money details — дополнительная секция только когда они нужны; unknown не заменяется цифрой. Смена уже заданного kind удаляет старые суммы/валюту/period/basis/rangeSource до нового patch. Коррекция goal или любого ответа отзывает подтверждение.

Каталог контрагентов, полная тренировка/разбор/replay, очередь, оплата и измерительные слои ниже — отдельная будущая дорожная карта. Нельзя выдавать их за работающие экраны текущего модуля.

## 4. Архитектура

**Действующее решение владельца — [TECH_STACK.md](TECH_STACK.md).** Весь наш runtime на TypeScript/Node.js; существующая PostgreSQL — единственное серверное хранилище. Собственный LiveKit и Python worker отменены.

~~~text
Браузер: Next.js/React/TypeScript → same-origin /api/intake → PostgreSQL
SDK ↔ LiveAvatar FULL без context: managed ASR / медиа / lip sync
Финальный ASR event → /events → owner POST /api/intake/:id/respond
/respond загружает server transcript и attempt
 → внутренний callback: Bearer + HMAC intake/epoch/deadline
 → прямой OpenAI Chat API / Anthropic → reply / changes / action
 → Zod ProfilePatch / ProfileControl / PostgreSQL
 → reply + view → browser SDK.repeat → LiveAvatar / ElevenLabs TTS
Speech start → SDK.interrupt + отмена/инвалидация предыдущего turn
Независимый cleanup → provider stop / deadline / TTL / budget
~~~

APP_ORIGIN — канонический origin UI. Внешний callback URL/tunnel не требуется: подписанный Bearer/HMAC boundary вызывается сервером in-process после owner-authenticated /respond. Provider helper настраивает только voice/TTS secret, не context/LLM configuration/Agent. Protected callback route остаётся для будущих интеграций. Receipts и cancellation защищают от повторной генерации/late writes.

B предоставляет PostgreSQL/auth/budgets/jobs/env; D — FULL SDK/callback/model intake/lifecycle; A — общие схемы и будущие денежные адаптеры; C — общую оболочку/форму и reusable capture. Своих LiveKit credentials/runtime, GPT Realtime, Redis/S3/Python нет. Raw audio/video не сохраняются. Подробности — [TECH_STACK.md](TECH_STACK.md).

Ниже сохранены проектные материалы будущего финансового слоя и исходного хакатонного pitch. Их числовые сценарии/Agent-транспорт не являются текущим универсальным intake-контрактом; Agent-планы отменены, интеграции требуют отдельного актуального решения.

### 4.1 Будущий финансовый движок: модели вокруг детерминированного ядра

| Агент | Тип | Вход → выход | Когда |
|---|---|---|---|
| Сценарист | LLM, 1 раз | QuizAnswers → `ScenarioConfig` по строгой JSON-схеме | старт сессии |
| Классификатор | LLM, быстрая модель | реплика пользователя → `{moveType, amount?, hasReason, tone}` | каждый ход |
| Ядро | чистый TypeScript | `(CoreState, Move)` → `(CoreState', CounterpartAction)` | каждый ход |
| Актёр | LLM, стрим | `CounterpartAction` + персонаж → текст реплики | каждый ход |
| Разборщик | код + LLM | `SessionState` + `VoiceMetrics` → `Debrief` | конец сессии |

**Правила:**
- Все цифры считает код. Денежную фразу формирует ядро/шаблон; актёр не меняет число. До публикации проверить весь ответ, включая суммы словами; одной регулярки по цифрам недостаточно. При сомнении — безопасный шаблон A.
- Классификатор возвращает только значения из закрытого списка. Невалидный ответ → повтор один раз → `offtopic`.
- Ядро покрыто юнит-тестами на таблицу переходов. Классификатор покрыт 30 тестовыми репликами.

### 4.2 Модель данных (ранний черновик, не контракт реализации)

Ниже сохранён набросок исходной идеи. Для реализации использовать полные схемы [плана A](docs/superpowers/plans/2026-11-15-01-engine.md): суммы в целых центах, `objective`, `reservationAmountMinor`, null при отсутствии сделки. Профиль первого звонка и наблюдения описаны в [плане D §4](docs/superpowers/plans/2026-11-15-04-avatar-intake.md); они не подмешиваются в `CoreState`.

```ts
type MoveType =
  | 'state_number' | 'justify' | 'concede' | 'ask_question'
  | 'hold_silence' | 'ultimatum' | 'accept' | 'offtopic';

interface Move { type: MoveType; amount?: number; hasReason: boolean; raw: string; t0: number; t1: number; }

interface ScenarioConfig {
  kind: 'raise' | 'offer' | 'rent' | 'bill' | 'custom';
  currency: 'USD';
  userCurrent: number; userTarget: number; marketLow: number; marketHigh: number;
  ceiling: number;            // из рыночного диапазона, не выдумка
  concessionStep: number;     // на сколько уступает за раз
  objections: Objection[];    // список с условиями снятия
  persona: { name: string; role: string; archetype: Archetype; voiceId: string; avatarId: string };
  patience0: number; trust0: number;
}

interface Objection { id: string; text: string; clearedBy: MoveType[]; cleared: boolean; }

interface CoreState {
  offer: number | null;        // текущее предложение собеседника
  userLast: number | null;     // последняя цифра пользователя
  patience: number; trust: number;   // 0..100
  objections: Objection[];
  turn: number;
  ended?: 'accepted' | 'walked_away' | 'timeout';
}

type CounterpartAction =
  | { kind: 'hold' } | { kind: 'concede'; to: number } | { kind: 'object'; objectionId: string }
  | { kind: 'accept'; at: number } | { kind: 'walk_away' } | { kind: 'probe' };

interface VoiceBaseline { wpm: number; f0Mean: number; f0Std: number; pauseRatio: number; rms: number; fillersPerMin: number; }

interface TurnVoice { turn: number; wpm: number; f0Mean: number; f0Std: number; pauseBeforeNumberMs?: number; fillers: number; rmsDipAtNumber: boolean; tension: number; }

interface DebriefRow { turn: number; move: MoveType; note: string; moneyEffect?: number; meterEffect?: { patience?: number; trust?: number }; voice?: TurnVoice; betterLine?: string; }

interface Debrief { leftOnTable: number; ceiling: number; stoppedAt: number; rows: DebriefRow[]; persuasionScore: { value: number; rationale: string }; }
```

### 4.3 Таблица переходов ядра (набросок, довести в коде)

| Ход пользователя | Условие | Эффект на состояние | Действие собеседника |
|---|---|---|---|
| `state_number` с обоснованием | amount ≤ ceiling | trust +3 | `concede` на шаг к amount, если открытых возражений нет; иначе `object` |
| `state_number` без обоснования | | patience −2 | `object` (первое открытое) |
| `state_number` | amount > ceiling·1.15 | patience −5 | `hold` + возражение «вне диапазона» |
| `justify` | закрывает условие возражения | возражение cleared, trust +2 | `concede` на шаг |
| `concede` | пользователь снизил цифру | фиксируем уступку в журнале отдельно от итогового разрыва | `accept`, если ≤ offer+step, иначе `hold` |
| `ask_question` | | patience +1 | `probe` (раскрывает подсказку) |
| `hold_silence` | после возражения | patience −1, trust +1 | `concede` на полшага |
| `ultimatum` | trust < 40 | patience −10 | `walk_away` при patience < 15, иначе `hold` |
| `ultimatum` | trust ≥ 40 | | `concede` на шаг |
| `accept` | | ended = accepted | — |
| `offtopic` | | patience −1 | `hold` |
| любой | patience ≤ 0 | ended = walked_away | `walk_away` |

«Оставил на столе» для зарплаты = `max(0, ceiling − финальная сумма)` при принятии. Уступки из журнала повторно не прибавляются. Для аренды знак направления обратный; при отсутствии сделки результат null. Полные правила — план A.

## 5. Голосовой контур: LiveAvatar FULL и прямые API

### 5.1 Текущий видеокоуч

- LiveAvatar FULL работает без provider context: managed ASR event фиксируется через owner API, затем /respond загружает server transcript и вызывает внутренний callback с Bearer + HMAC intake/epoch/deadline.
- Наш сервер задаёт prompt/candidate и напрямую вызывает OpenAI Chat Completions или Anthropic Messages. Compact JSON reply/changes/action валидируется и проходит через ProfileControl.
- ElevenLabs TTS voice импортирован в LiveAvatar; разговорного ElevenLabs Agent, dashboard tools, второго speaking widget и Agent token API не нужно.
- Ответ /respond поступает в один SDK.repeat output; speech start вызывает SDK.interrupt и отмену/инвалидацию старого turn. Camera local-only; paid session после Connect, review/End закрывают её. Внешний callback/tunnel не нужен.
- Следующие калибровка/измерения/voice clone — будущие отдельные opt-in слои. Они не являются текущими включёнными capabilities.

### 5.2 Калибровка
- 20 секунд чтения нейтрального текста → `POST /api/voice/baseline` → Scribe batch с таймстемпами слов → `VoiceBaseline`.
- Параллельно в браузере считаем RMS и F0, чтобы базовая линия была и для живых метрик.
- Кнопка «Пропустить»: метрики в разборе абсолютные, без сравнения, с пометкой.
- Первый созвон не заменяет нейтральную калибровку: запись знакомства может быть только `observed_intake` для сравнения одинаковой пробы, а не физиологической нормой.

### 5.3 Разбор голоса
- Запись сессии (только дорожка пользователя) → `POST /api/voice/analyze` → Scribe batch, verbatim, таймстемпы.
- Режем по ходам (границы известны из сессии), считаем на каждый ход: темп, паразиты, паузу перед первой цифрой, провал громкости в момент цифры, F0 среднее и разброс.
- `tension` = взвешенная сумма отклонений от базовой линии (рост F0, рост темпа, доля пауз). Формула показана на экране.
- `persuasionScore` считает LLM по рубрике (аргумент, цифра с обоснованием, нет извинений, нет уступки без причины). Подписывается как «оценка модели».
- Для первого звонка D отдельно разбирает filler words, повторы и формулировки по raw/verbatim Scribe v3, проверяя цитаты и таймкоды. ASR не гарантирует обнаружение всех речевых запинок; диагностического «процента заикания» нет. Локальная камера даёт движения/положение головы, а не доказательство нервозности.

### 5.4 Опционально: «Послушать, как надо, твоим голосом»
- Из калибровочной записи делаем мгновенный клон (IVC), озвучиваем `betterLine` голосом пользователя.
- Явное согласие галочкой, удаление клона после сессии. Проверить качество до включения в питч.

### 5.5 Защита расходов
- Сессия ≤ 5 минут, автозавершение.
- ≤ 3 сессии на IP в день, глобальный дневной потолок минут.
- Проверить в дашборде, сколько минут Agents и Scribe дают имеющиеся кредиты. Оставить запас на жюри ×10 сессий.

### 5.6 Проверить в первые два часа
- Verbatim в Scribe правда оставляет «um/uh» (от этого зависит метрика паразитов).
- Agent работает в Safari и Chrome на macOS, на телефоне хотя бы не падает.
- Задержка хода с buffer words укладывается в 3–5 с.

## 10. Дек, 10 слайдов

1. Название, одна строка: «Отрепетируй разговор до того, как он обойдётся тебе в деньги».
2. Боль: цитата из интервью + одна проверенная цифра.
3. Пользователь: кто, когда, что теряет (с формулой «$X в год»).
4. Продукт за 20 секунд: знакомство с AI-коучем → подтверждение профиля → собеседник → переговоры → разбор. Скриншоты только готовых возможностей.
5. Почему не ChatGPT: скрытое состояние, не сдаётся, честный разбор. Сравнение из двух реплик.
6. Голосовой слой: журнал с двумя колонками, «на 4-м ходу голос поднялся на 18% и ты уступил $8 000».
7. Как устроено: ядро на TS, LLM по краям, ElevenLabs. Схема из раздела 4.
8. Деньги: пакет на разговор, платный генератор, честная LTV как гипотеза.
9. Рынок и расширение: все разговоры о деньгах, один движок, сценарий = конфиг.
10. Команда, что сделали за 24 часа, что дальше.

## 11. Вопросы жюри и ответы

- **Откуда вы знаете потолок?** Это параметр сценария, взятый из диапазона, который ввёл пользователь. Мы говорим «против твоего диапазона», а не «твой босс бы заплатил».
- **Почему не дать ИИ торговаться за меня?** Счёт делегировать можно, разговор с начальником или арендодателем нет: его произносит сам человек.
- **Зачем вернутся?** Разговоры о деньгах случаются несколько раз в год, очередь разговоров с датами, переигровка, новые сценарии.
- **Чем отличается от тренажёров переговоров?** Скрытое состояние и счёт денег, а не оценка «молодец». Плюс голос относительно твоей нормы.
- **Что захардкожено?** Ничего в цифрах: все суммы считает ядро, LLM их не трогает. Репо открыт.
- **Насколько точны голосовые метрики?** Темп, паузы, паразиты, громкость, высота: измерения. Напряжение: индекс с видимой формулой. Убедительность: оценка модели, подписана как оценка.

## 12. Риски и страховки

| Риск | Страховка |
|---|---|
| Микрофон у жюри не работает, Safari капризничает | Текстовый режим везде; кнопка «посмотреть пример разбора»; проверка Safari в слое 2 |
| Видеоаватар медленно подключается или завис | Порог ожидания 15s, переход в аудио/форму с сохранением профиля; старый канал закрывается |
| Зарплата распознана неверно | Деньги с валютой/периодом/gross-net, подтверждение человеком и отмена зависимых расчётов после правки |
| Движения ошибочно трактуются как нервозность | Только наблюдаемые события, quality/coverage и примеры; эмоции/диагнозы не выводятся |
| Классификатор нестабилен | 30 тест-реплик, повтор при невалидном, быстрая модель, `offtopic` как безопасный дефолт |
| Задержка хода > 5 с | buffer words, стрим актёра, быстрая модель для классификатора |
| Scribe вычищает паразиты | проверить в H+2; если да, отдельный проход или другой STT только для паразитов |
| Открытый кошелёк (без логина) | лимит на IP, длина сессии, глобальный потолок, ключи только на сервере |
| Объём не влезает | слои; заморозка в H+17; флаги на недоделанное |
| Клон голоса плохого качества или сомнителен этически | явное согласие, удаление после сессии; не ставить в питч без проверки |
| Непроверенная статистика на слайде | в дек идут только проверенные цифры |
| Размер команды: сайт говорит 1–3, нас четверо | уточнить у организаторов (tech@zimran.io) до сдачи |

## 15. Первый опыт: действующая редакция v2

**Смысл:** помочь подготовить собственный разговор, понять цель и попробовать вступление. Ни salary-only анкета, ни скрытый экзамен не соответствуют этому объёму. Спокойная режиссура, optional камера, исправления и человеческое подтверждение обязательны.

**Принято:** LiveAvatar FULL + прямой OpenAI Chat API/Anthropic + импортированный ElevenLabs TTS; PostgreSQL; один говорящий канал. Common kind/description/goal/counterpartRole, optional desiredTone и money. Полный roleplay/debrief и financial readiness — отдельные будущие проверки. Сохранять 24h TTL, no raw media, owner/Origin, CAS/receipts, configured deadline ≤300s, provider stop и независимый cleanup.

| Этап | Приёмка | Текущий предел доказательства |
|---|---|---|
| G0 | Реальный FULL ASR → owner /respond → internal signed boundary → SDK.repeat/media, один звук, interruption и stop | Ключи/HTTP 200 и генерация обеих моделей прошли; живое медиа ещё не принято |
| G1 | Любая custom/nonfinancial тема → review → confirm; corrections/reload/денежный reset/legacy | Unit/API/browser доказательства фиксируются в progress, не заменяют live call |
| G2 | Отдельные speech/visual observations с quality/evidence | Поздние выключенные флаги; не объявлять работающими |
| G3 | Реальный desktop/mobile путь и production cleanup/budget/retention | Только измеренная приёмка, без выдуманной latency или стоимости |

На проверенном Free-аккаунте: одна сессия, максимум 120s; sandbox Wayne ≤60s только для технического теста. 10 LiveAvatar credits при FULL 2 credits/min — около 5 минут aggregate usage, не пятиминутная Free-попытка. TTS и модели оплачиваются отдельно. Покупка/overage не требуются.
